Immich Backup Setup Checklist
==============================

□ SETUP (First Time)
   □ Copy config file: cp backup-config-local.sh backup-config.sh
   □ Edit backup-config.sh with your paths
   □ Verify Immich is running: docker ps
   □ Test backup: ./backup-immich.sh
   □ Verify backup: ./verify-backup.sh /path/to/backup

□ FOR SMB/NETWORK SHARES (Ubuntu)
   □ Run setup: ./setup-ubuntu.sh
   □ Or manually install: sudo apt-get install cifs-utils rsync
   □ Test mount manually first
   □ Create credentials file (recommended)
   □ Configure sudo permissions

□ AUTOMATION (Optional)
   □ Set up cron job for automatic backups
   □ Configure log rotation for backup logs
   □ Set up monitoring/alerts for failed backups
   □ Document restore procedure for your team

□ BEST PRACTICES
   □ Keep at least 7 days of backups
   □ Test restore procedure quarterly
   □ Verify backups weekly
   □ Backup before Immich upgrades
   □ Store backups off-site for disaster recovery
   □ Document backup/restore procedures

□ REGULAR MAINTENANCE
   □ Weekly: Verify latest backup
   □ Monthly: Test restore to ensure backups work
   □ Quarterly: Review backup retention policy
   □ As needed: Update backup scripts

QUICK COMMANDS
==============

Backup:   ./backup-immich.sh
Verify:   ./verify-backup.sh /path/to/backup/immich_backup_YYYYMMDD_HHMMSS
Restore:  ./restore-immich.sh /path/to/backup/immich_backup_YYYYMMDD_HHMMSS
Help:     See README-BACKUP.md or QUICKSTART-BACKUP.md
